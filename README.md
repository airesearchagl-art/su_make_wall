# MakeWall for SketchUp

MakeWall は、BIM ツール（Revit など）ライクな直感的でスピーディな壁モデリングを SketchUp 上で実現するプラグインです。

建築設計の初期ボリューム検討やレイアウト作成において、圧倒的なモデリング効率の向上（設計 DX）を目指して開発されました。

---

## 主な機能 (Features)

### 連続描画と自動留め継ぎ（マイター処理）
線を引く要領でクリックしていくだけで、3D の壁が連続して立ち上がります。L 字コーナー、鋭角・鈍角、さらには「始点に戻って閉じる（ループ閉合）」際にも、壁の端部が自動で斜めにカットされ、綺麗に包絡されます。

### リアルタイム・パラメータ UI
画面端に常駐する専用パネル（HtmlDialog）から、壁の「高さ」「厚み」「基準線（中心・左・右）」をいつでも変更可能。値を変更すると、描画中の壁のプレビューに即座に反映されます。

### 正確なモデリングのサポート
- **軸ロック:** 矢印キー（→ 赤軸、← 緑軸、↑ 青軸）で描画方向を拘束
- **数値入力 (VCB):** `3000` や `3.0m` と打ち込むことで正確な寸法の壁を生成

## インストール方法 (Installation)

1. リリースページから最新の `SuMakeWall_vX.X.X.rbz` をダウンロードします。
2. SketchUp を起動し、上部メニューから `拡張機能` > `拡張機能マネージャー` を開きます。
3. 下部の `拡張機能をインストール` ボタンをクリックし、ダウンロードした `.rbz` ファイルを選択します。
4. インストール完了後、ツールバーに MakeWall のアイコンが追加されます。
